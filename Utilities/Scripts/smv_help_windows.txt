Ashton Smokeview help (Windows)
================================

Open an FDS case by double-clicking its .smv file, or run:
  smokeview.exe C:\path\to\case.smv

Result-review shortcuts in the Smokeview window
  Ctrl+I  Visibility slices (Ctrl+L is an alternative)
  Ctrl+T  Temperature slices
  Ctrl+V  Velocity slices
  Ctrl+P  Pressure slices
  Ctrl+U  Unload data and restore the previous view
  Ctrl+X  X-minimum, X-maximum and exterior views
  Ctrl+Y  Y-minimum, Y-maximum and exterior views
  Ctrl+Z  Z-minimum, Z-maximum and exterior views

Hold Shift with a slice shortcut to cycle backwards. Each slice shortcut
loads the slice, sets its colourbar and bounds, clips the model at that
plane, and fits the view. Ctrl+U restores the earlier camera and clipping.

Capture result slices
  Open Capture result slices from the Start menu, or right-click a .smv file
  and choose Capture result slices. The window lets you choose one case or
  all cases in a folder, slice types, one or more times, and an output folder.
  For command-line capture, run:
  capture_result_slices.cmd C:\path\to\case.smv

The capture launcher runs a separate Smokeview process. You can keep an
interactive Smokeview window open. Images are saved beside the case in a
folder named case_slice_captures. The MSI includes Python and ImageMagick
for capture; no separate installation is needed.
The capture window opens in dark mode. Its advanced slice-position control
can scan a case and select planes such as Y=3 or Y=5.

For all capture options, run:
  capture_result_slices.exe --help

Useful options: --planes Y=3,Y=5, --overwrite, --no-crop, -o DIRECTORY, --time SECONDS,
--prefix NAME, and --crop-padding PIXELS.
