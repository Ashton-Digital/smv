Ashton Smokeview: Quick help
=============================

Open a case
-----------
Double-click a .smv file, choose Ashton Smokeview from the Start menu, or run:
  smokeview.exe C:\path\to\case.smv
Keep the case's associated slice and data files beside the .smv file.

Result-review shortcuts (inside Smokeview)
------------------------------------------
  Ctrl+I  Visibility slices (Ctrl+L also works)
  Ctrl+T  Temperature slices
  Ctrl+V  Velocity slices
  Ctrl+P  Pressure slices
  Ctrl+U  Unload data and restore the previous view
  Ctrl+X  X-minimum, X-maximum and exterior views
  Ctrl+Y  Y-minimum, Y-maximum and exterior views
  Ctrl+Z  Z-minimum, Z-maximum and exterior views
Hold Shift with a slice shortcut to cycle backwards. Slice shortcuts load
matching data, set the colourbar and bounds, clip the model, and fit the view.

Capture result slices (window)
------------------------------
Open Capture result slices from the Start menu or the .smv right-click menu.
The right-click action fills in that case automatically.

  1. Select one .smv file or a folder. Include subfolders is on by default.
  2. Select the slice types and enter times in seconds, separated by commas
     (for example 60, 120, 180).
  3. Optionally choose an output folder. Blank saves beside each .smv file in
     a new case_slice_captures folder.
  4. Choose whether to crop images and replace existing captures.
  5. If needed, expand Advanced and scan the input. Uncheck any slice positions
     to omit them. For a folder, use Previous and Next to review each .smv
     case separately. Cases with no checked positions are skipped. Otherwise
     every matching plane is captured. Add position manually is available for
     a position missing from the scan and applies to the case shown.
  6. Click Capture slices. The Capture log shows progress; Cancel stops a run.

The window opens in dark mode and can switch to light mode. Captures use a
separate Smokeview process, so an interactive Smokeview window may stay open.
The MSI includes Python, PySide6 and ImageMagick for the capture window.

Command-line capture
--------------------
  capture_result_slices.cmd C:\path\to\case.smv
  capture_result_slices.exe --help
Useful options: --planes Y=3,Y=5, --overwrite, --no-crop, -o DIRECTORY,
--time SECONDS, --prefix NAME, and --crop-padding PIXELS.
